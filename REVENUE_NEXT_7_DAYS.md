# HotelRADAR Revenue Checklist: Next 7 Days

Last updated: March 2026

## Objective

Get HotelRADAR into paying use next week.

This checklist is about revenue readiness, not feature expansion.

## Must Be True Before Charging

### 1. Dashboard trust is stable
- no obviously wrong event dates
- no contradictory confidence messages
- no stale critical alerts lingering incorrectly
- no broken or disappearing UI elements

### 2. OTA parity is credible
- live rows appear where available
- mismatch logic is understandable
- parity gap messaging is clear

### 3. One stay-date recommendation is easy to explain
- demand score
- current price
- market position
- suggested action
- top signal drivers

### 4. Goa and Mumbai remain tightly scoped
- no expansion distractions
- no unsupported cities
- competitor sets remain curated

## This Week’s Priority Actions

### Day 1

- confirm no major deploy drift

### Day 5
- run demos

- close first account or convert demo into paid onboarding

## Must-Fix Engineering Items This Week

Only work items that affect trust or charging:
- event data correctness
- OTA parity clarity
- deploy reliability
- alert correctness
- dashboard stability

Avoid spending this week on:
- PMS integrations
- automation publishing
- new city support
- deep ML work
- portfolio expansion

## Demo Checklist

Before every live demo:
- verify production health endpoint
- verify current dashboard data for selected hotel
- verify event list is correct
- verify OTA rows are current enough
- verify suggested price is visible and explainable
- verify no lock confusion in front of the customer

## Sales Checklist

For every target hotel:
- identify the decision maker
- identify the pricing pain
- use one real stay-date example
- show one missed revenue or leakage story
- offer narrow scope with support included

## Success Metric for Next Week

Primary success:
- first paying hotel

Secondary success:
- 2 to 3 qualified live demos
- 1 strong commercial case study setup

## Rule for the Week

Do not chase more features.

Chase:
- trust
- clarity
- pricing action
- paid conversion
