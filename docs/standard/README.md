# HotelRADAR standard documentation

This folder is the starting point before any new implementation.

HotelRADAR is being built as a Hotel Market Intelligence product, not a traditional RMS clone. The product should reduce the gap that older RMS tools leave open: weak market context, poor external signal capture, no explanation of where the hotel is commercially exposed, and limited actionability for owners, GMs, revenue managers, and sales teams.
